## Observations

- Scores come from 40 held-out rows per dataset and from short DNN and QML runs, so they show that each paradigm trains and is scored the same way, not how good each model can get (Test Plan 7: predictive quality is not a test target).
- banking.csv, healthcare.csv, insurance.csv, telecom.csv report the same split fingerprint. The fingerprint hashes only the test labels, and these datasets have the same class counts, so the seeded stratified split gives the same label sequence. It still proves what REQ-PP-10 asks: every model in one run was scored on one split. Hashing the test row indices as well would make it unique per dataset (minor, not a defect).
